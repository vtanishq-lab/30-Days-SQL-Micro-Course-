# 🏥 Hospital Data Analysis Using SQL

## 📌 Project Overview

This project is an SQL-based analysis of a **Hospital Data dataset**. The objective of this assignment was to use SQL queries to analyze hospital operations and extract meaningful insights related to patients, doctors, departments, hospital stays, and medical expenses.

This assignment was provided by **Satish Dhawale, Founder of Skill Course**.

## 🎯 Objectives

The analysis focuses on answering important business and healthcare-related questions using SQL, such as:

* Total number of patients
* Average number of doctors per hospital
* Top 3 departments by patient count
* Hospital with the highest medical expenses
* Average medical expenses
* Longest hospital stay
* Total patients treated per city
* Average length of stay by department
* Department with the lowest number of patients
* Monthly medical expenses

## 📊 Key Analysis

The SQL queries were used to analyze:

1. Patient volumes across hospitals and cities
2. Doctor availability across hospitals
3. Department-wise patient distribution
4. Hospital medical expenses
5. Length of hospital stays
6. Department-wise average stay duration
7. Monthly medical expenses
